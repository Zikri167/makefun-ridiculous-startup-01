## What it does

`main.ts` (Node 22, stdlib only, no network, no API keys) writes a single
sentence — one bizarre startup pitch, at most 200 characters — to
`/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).

The pitch:

> We lease a herd of goats to weed solar farms, and the operators pay per acre because goats are cheaper than mowers and cannot crack a panel.

## Run it

```sh
node main.ts
cat /output/entry.txt
```
